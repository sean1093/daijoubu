# 日本旅遊小幫手 (Daijoubu)

> 不會日文，去日本也大丈夫。

不用學日文，也不用開口。遇到狀況時打開手機、點一個大按鈕：App 替你**念出日文**，或把日文**放大給對方看**，10 秒內把事情辦完。

- **對象：** 不會日文、去日本旅遊的每一個人。
- **先填好，到時候不用想：** 出發前自己（或請家人朋友幫忙）填好飯店、行程和聯絡資料；到了日本打開就能用，不用打字、不用搜尋。
- **形式：** 手機網頁，可加到主畫面，離線也能用。不用註冊、不用下載 App。
- **隱私：** 沒有後端。資料只存在自己的手機裡；要給別人用時，資料放在連結的 `#` 後面傳過去，不會送到任何伺服器。
- **架構：** Vite + TypeScript + Tailwind CSS 的純前端靜態網站，部署在 GitHub Pages。

> 語言：UI 文字為繁體中文（台灣用語）；程式碼與註解為英文。

> 完整規格見 [`docs/spec.md`](docs/spec.md)；旅客痛點調查與對應改善見 [`docs/research.md`](docs/research.md)。

## 功能

### 🆘 我需要幫忙
首頁最大的紅色按鈕。按下去就是一張給路人、站務員或警察看的日文卡片：「我不會說日文，我迷路了，請幫我聯絡家人／請告訴我怎麼回這間飯店」，自動帶入飯店地址和家人電話。下方有 110、119、駐日代表處急難電話，以及派出所（交番）的說明。

### 🚃 情境句庫
交通、飯店、餐廳、便利商店、購物、藥妝店、廁所和問路、緊急和醫療。每一句都有中文、日文（附振假名）、拼音、播放和慢速播放，還有全螢幕「給對方看」。

交通做得最深：「我想去〇〇站」「這班車有停〇〇嗎」直接用預先填好的站名，點站名按鈕就好，不用打字。

### 👉 雙向指指卡
- **給對方點選：** 上面是日文問題，下面是日文選項（はい／いいえ、幾號月台、往哪邊走）。對方用手指一點，你這邊就顯示中文。
- **店員可能會說：** 「袋子需要嗎？」「要加熱嗎？」「內用還是外帶？」可以播放、看中文翻譯，再點中文回答。
- **萬用救援句：** 請用はい／いいえ回答、請寫在這裡、請說慢一點。

### 💊 醫療卡和過敏卡
由預先填好的慢性病、常用藥（成分）、過敏與飲食限制自動產生日文卡片。另有症狀指指卡（頭痛、發燒、腹瀉、暈眩、胸痛……）和「我有旅遊保險」「請幫我叫救護車」。

### 🖨️ 紙本備份
一鍵列印信用卡大小的護貝小卡：飯店卡、求救卡、醫療卡、過敏卡、緊急電話卡。手機沒電也不怕。

### 看得清楚、按得到
- 預設就是大字，可以再調成特大字；按鈕都很大。
- 首頁就是情境大按鈕，選單最多一層；除了設定頁，沒有任何輸入框或搜尋。
- 圖示搭配文字；淺色與深色模式的文字對比都通過 WCAG AA。
- 全螢幕卡片可以橫拿，字會跟著放大。

## 怎麼設定

1. 打開網站 → 首頁最下方「設定資料」。
2. 填稱呼、飯店（日文名稱、地址、電話）、每天要去的車站或地點、緊急聯絡人、健康資料。都是選填，填越多越好用。
3. 自己用的話，填完就好了。幫別人設定的話，按「產生分享連結」用 LINE 傳過去，或讓對方用相機掃 QR code。
4. 點開連結就自動匯入，之後直接開網站就好。

> ⚠️ 連結裡有地址、電話和健康資料，只傳給本人，不要貼到群組。
>
> 建議**出發前一兩天**再傳，並在出發當天打開一次：有些手機的瀏覽器會清掉太久沒開的網站資料。

## 聽不到聲音？

發音用瀏覽器內建的語音（Web Speech API），不需要網路，但手機要有日文語音：

- **iPhone／iPad：** 設定 → 輔助使用 → 朗讀內容 → 聲音 → 日文，下載一個語音（推薦「增強版」）。
- **Android：** 設定 → 系統 → 語言 → 文字轉語音輸出 → Google 語音服務，安裝日文語音資料。

就算沒有聲音，「給對方看」一樣能用——那本來就是主要的用法。

## 開發

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev      # 本機開發
npm test         # 內容檢查與單元測試
npm run build    # 型別檢查＋建置到 dist/
```

`npm test` 會檢查所有內容：每個漢字都有讀音、沒有重複的 id、每句都有中文翻譯、每個情境至少 12 句、緊急電話都附上來源與查證日期。

### 截圖檢查

`docs/screenshots/` 是手機尺寸（390×844）的畫面截圖：首頁（淺色／深色／特大字／沒有資料）、求救卡、橫拿的放大卡片、交通句子清單與單句詳情、給對方點選（點選前／後）、對方說、萬用句、醫療卡、設定資料。重新產生：

```bash
npm run build && npx vite preview --port 4173 &
CHROMIUM=/path/to/chrome NODE_PATH=$(npm root -g) node scripts/screenshots.cjs scripts/sample-profile.json docs/screenshots
```

腳本也會檢查頁面錯誤和手機寬度下的橫向捲動。

### 部署

推到 `main` 時 GitHub Actions 會自動測試、建置並部署到 GitHub Pages。第一次需要在 repo 的 **Settings → Pages → Source** 選 **GitHub Actions**。

路由都在網址的 `#` 後面、資源用相對路徑，所以放在任何子路徑都能運作。

### 新增句子

句子寫在 `src/content/scenes/*.ts`，日文用 `{漢字|かな}` 標記讀音、詞與詞之間空一格：

```ts
{
  id: "transport-stop-at",
  zh: "這班車有停〇〇嗎？",
  jp: "この {電車|でんしゃ} は $stop に {止|と}まります か。",
  fallback: "この {電車|でんしゃ} は ここ に {止|と}まります か。",
  answers: "yesNo",
}
```

`$stop` 會換成預先填好的站名。日文請用自然、禮貌的「です／ます」體。
