# 設計語言：車站標示

這個 App 會在月台、店門口、計程車裡被打開，常常是在慌張的時候。最適合參考的不是一般 App，而是旅客已經看懂的東西：**日本車站的標示**。這也是這次改版的出發點：拿掉 emoji，換成一套跟車站標示一樣安靜、一致的視覺。

## 原則

1. **不用 emoji。**
   - emoji 在每支手機上長得不一樣，也會讓畫面看起來像聊天機器人產生的。
   - 情境、功能一律改用 `src/ui/dom.ts` 的線條圖示：24×24 格線、2px 線寬、圓角端點。
   - 地點、服務類的圖示（`train`、`bed`、`bowl`、`store`、`restroom`、`firstaid`…）參考 JIS 公共標示圖示的造型。
2. **圖示放在實心方形底板上**（`pictogram()`），跟站內標示一樣。旁邊一定有文字，圖示本身只是裝飾（`aria-hidden`）。
3. **顏色只代表意思，不拿來裝飾。**

   | 顏色 | Token | 意思 |
   |---|---|---|
   | 藍 | `ai` | 可以點的東西、一般情境 |
   | 紅 | `shu` | 緊急：求救、醫療、110／119 |
   | 黃 | `exit` | 出口、電梯，比照車站出口標示的黑字黃底 |
   | 綠 | `ok` | 讓對方點選回答 |
   | 淡黃 | `warn-soft` | 提示、萬用句 |

4. **安靜的外框。**
   - 1px 細線（`ring-1 ring-hair`），不加陰影。
   - 圓角最大 12px（`rounded-xl`）；按鈕用 `rounded-lg`，不用膠囊形。
5. **段落標題像月台標示牌**（`heading()`）：一條短色條加上粗體字。
6. **文案是指示，不是聊天。**
   - 短句、祈使句，不加表情符號，也不說「👉」「👇」。
   - 例：「請把畫面拿給對方看」「選一種方式」。
   - 方向直接用箭頭字元（→ ← ↑）。
7. **勾選要像紙本表格。** 症狀、飲食習慣都用會填滿的方框加勾，跟醫院掛號單一樣。

## 為什麼

- **熟悉。** 去過日本的人都看過這些標示：紅色是緊急，黃底黑字是出口。
- **一致。** SVG 在每支手機、深色模式、列印小卡上看起來都一樣。
- **可信。** 求救卡、醫療卡要交給陌生人看。看起來越像正式的文件，對方越願意認真讀。
